# Vijeta Nehra — Portfolio

React + Vite portfolio with a premium black-and-white design.

## Run on your computer
1. Extract this ZIP.
2. Open the `vijeta-portfolio` folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev` and open the localhost URL shown in the terminal.

## Before publishing
- Replace `yourusername` in `src/components/Footer.jsx` with your real GitHub and LinkedIn usernames.
- Check the project links and details.
- To add a CV download later, place your PDF at `public/resume.pdf`.

Build using `npm run build`.
